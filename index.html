Interpretation

This is an educational estimate based on visible workload and literature-calibrated averages, not a measurement from the provider's data centre. The range is designed to make the main uncertainty visible rather than hide it behind a single precise number.

Method and assumptions

The estimator reconstructs the visible input context before each assistant answer, counts the visible output, and adds only tool operations that can be detected in the imported chat. The user supplies the model and thinking level.

Echat = Σ [ text-token energy + visible tool energy ]

Water is reported as direct data-centre water plus electricity-related water, using the location-independent operational coefficients fixed in the accompanying report.

Wchat = 4.1 mL/Wh × Echat
  • Output energy classes: 0.15, 0.50, 1.00 and 1.50 Wh per 1000 generated tokens.
  • Input cost: 10%, 20% or 35% of output-token cost depending on visible context length.
  • Thinking multipliers: 0, 1, 3, 7 and 14 hidden-token equivalents.
  • Visible tools: web 0.04 Wh/search; short code 0.01 Wh/run; image understanding 0.06 Wh/image; image generation 2.9 Wh/image; video generation 25 Wh/clip.
  • Water: 0.2 mL/Wh direct + 3.9 mL/Wh electricity-related.
  • Excluded: hidden prompts, cache hits, invisible retries/tools, server location, exact hardware, training and manufacturing water.
Privacy and supported imports

Your chat is not uploaded by this website. The application has no backend and the page's Content Security Policy blocks network connections from the estimator. Files are opened with browser APIs and discarded when the page is closed.

Dedicated parsers are included for ChatGPT conversation exports, Claude conversation exports and Gemini Takeout activity. Tolerant JSON/HTML/text parsers cover Grok, DeepSeek and generic saved chats. ZIP, TAR/TGZ and DOCX processing is implemented locally. For a PDF printout, copy/paste the visible transcript instead.
